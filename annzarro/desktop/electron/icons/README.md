# Application Icons

This directory should contain the following icon files for building the desktop application:

- `icon.png` - PNG image at 512x512 pixels (for general use)
- `icon.icns` - macOS icon bundle 
- `icon.ico` - Windows icon bundle
- For Linux, you'll need icons of different sizes:
  - `16x16.png`
  - `32x32.png`
  - `48x48.png`
  - `64x64.png`
  - `128x128.png`
  - `256x256.png`
  - `512x512.png`

You can use a tool like `electron-icon-maker` to generate all these icons from a single high-resolution PNG image.
