Server Error

The AnnZarro server failed to start. This could be due to:

  • Missing Python dependencies (numpy, zarr, flask)
  • Another application using the same port
  • Permission issues
  • Python module structure not correctly loaded

Try the following steps:

  1. Restart the application
  2. Install required Python packages manually: pip install numpy zarr flask
  3. Check if port 8000 is already in use by another application
  4. Check that you have proper permissions for the data directory
  5. Try running the application from a terminal to see detailed error messages
