# Code of conduct

AnnZarro follows the [scverse code of conduct](https://scverse.org/about/code_of_conduct/), which
is the [NumFOCUS code of conduct](https://numfocus.org/code-of-conduct): be kind to others, do not
insult or put down others, behave professionally, and remember that harassment and exclusionary
jokes are not appropriate.

To report a problem, write to the maintainers (Dominik J. Otto, dotto@fredhutch.org, or
Manu Setty, msetty@fredhutch.org), or follow the reporting steps in the code of conduct above.
