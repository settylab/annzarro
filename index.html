Getting Started

Annzarro is a browser-based tool for visualizing single-cell data from AnnData objects stored in zarr format.

Loading Data

You can load data from:

  • Local files: Select a zarr directory or archive
  • URLs: Provide a URL to a zarr dataset
  • S3 storage: Connect to data in an S3 bucket
  • Demo data: Use the included sample datasets from the data/ directory
Visualization Panels

You can create multiple visualization panels with different layouts:

  • Single Panel: One full-width visualization
  • Horizontal Split: Two panels side by side
  • Vertical Split: Two panels stacked vertically
  • Quad Split: Four panels in a 2x2 grid
Gene and Cell Focus

You can select a gene or cell of interest in the navigation bar. This selection will be highlighted in relevant visualizations.

Data Exploration

Use the "Explore Structure" button to see the full structure of your AnnData object, including:

  • .obs: Cell metadata
  • .var: Gene metadata
  • .obsm: Cell embeddings (UMAP, PCA, etc.)
  • .layers: Alternative expression matrices
  • .uns: Unstructured annotations
DataTables

Use the powerful search and filter capabilities of DataTables to find specific cells or genes of interest.

STRING-DB Integration

For gene-focused visualizations, Annzarro can connect to STRING-DB to show protein interaction networks and gene set enrichment.
