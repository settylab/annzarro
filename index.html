Annzarro - Single-Cell Visualization Tool

Key Features
  • Browser-based: No Python installation required
  • Lazy Loading: Efficiently handles large datasets with zarr
  • Interactive Visualizations: Explore data with interactive plots
  • Flexible Panels: Create custom layouts with different panel types
  • Selection Sets: Create and manage cell and gene sets
  • Session Management: Save and restore your analysis state
Getting Started
  1. Click "Browse Data" to select a zarr dataset
  2. Use the persistent header to select genes and cells of interest
  3. Add panels using the "Add Panel" button
  4. Create plots, tables, and other visualizations
  5. Save your session to continue later
Panel Types
  • Plot: Interactive visualizations (scatter, violin, heatmap)
  • Cell Table: Browse and search cell data
  • Gene Table: Browse and search gene data
  • Gene Set: Analyze sets of selected genes
Keyboard Shortcuts
  • Ctrl + Click: Select multiple items
  • Shift + Click: Select a range of items
  • Esc: Clear current selection
