Annzarro: Python-based Single-Cell Visualization

Annzarro is a tool for visualizing and analyzing single-cell data stored in the zarr format. It provides interactive visualizations and analysis capabilities for exploring your data.

Getting Started
  1. Load Data: Click on "Load Data" in the navigation bar to load a dataset from a local file, URL, or S3 bucket.
  2. Demo Data: Click on "Demo Data" to browse and load available example datasets.
  3. Choose Layout: Select a layout to organize your visualization panels.
Features
  • Python Backend: Efficient data loading with Python's zarr library
  • Lazy Loading: Load only the data you need when you need it
  • Interactive Visualizations: Explore your data with interactive plots
  • Data Selection: Select cells and genes of interest
  • Metadata Exploration: Examine cell and gene annotations
Data Requirements

Annzarro expects AnnData objects saved in zarr format with standard structure:

  • .X: Main expression matrix
  • .obs: Cell annotations
  • .var: Gene annotations
  • .obsm: Multi-dimensional cell annotations (e.g., UMAP, PCA)
  • .layers: Named alternative expression matrices
  • .uns: Unstructured annotations
